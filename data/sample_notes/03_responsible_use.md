# Scope and intended use

StudyMate is a study-support tool for learners who need to locate explanations in supplied notes. It is not a grading system, a source of medical or financial advice, or a tool for handling personal data.

---

# Cost and limitations

The cost of one hosted answer includes embedding tokens plus language-model input and output tokens. The system can fail when the notes do not contain the answer, when retrieval selects an irrelevant chunk, or when a model ignores evidence. Showing source excerpts, keeping a refusal threshold and reviewing errors are practical mitigations.
